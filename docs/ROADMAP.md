# Roadmap (not shipped claims)

1. Measure lexical retrieval relevance and hallucinated conclusions using
   consented, reproducible fixtures.
2. Improve compact context capsules and on-demand tool discovery for small
   offline AI models.
3. Public independent Python-process and MCP STDIO handoff/crash-recovery
   fixtures have been added to main (post-v0.1.0). Future: reproducible
   evaluation across two independent model agents with verified task quality.
4. Add reproducible installer/release packaging and versioned migration tests.
5. Evaluate institutional requirements for multiple users, authorization,
   retention, independent audits and data isolation.

Only the deterministic Python/MCP process demonstration in item 3 is shipped
in current main. Other items and genuine model-to-model quality validation remain
future work. Tests are not equivalent to independent external audits.
